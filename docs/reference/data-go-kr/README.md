# 공공데이터포털 Open API 명세

공공데이터포털의 예탁결제원 검색 결과에서 한국예탁결제원 서비스 10개와 금융위원회 서비스 20개를 확인했습니다. 2026-11-25 연구(논문 등) 목적으로 개발계정을 신청해 30개가 승인됐으며, 서비스마다 대표 조회에서 실제 레코드를 확인했습니다.

필요한 항목이 SEIBRO 공식 Open API에 있으면 공식 API를 우선합니다. 공식 API에 필요한 기능이나 필드가 없으면 이 색인에서 공공데이터포털의 대응 조회를 찾습니다. [SEIBRO 공식 Open API](../README.md) · [겹치는 조회 비교](overlap.md) · [대표 호출과 실측 응답](verification.md)
