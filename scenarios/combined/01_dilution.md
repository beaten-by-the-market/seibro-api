# 1-01 희석주식수 분석 — 상장주식수 + 전환·행사 가능 물량 + 의무보유

[노트북](01_dilution.ipynb) · [Colab에서 열기](https://colab.research.google.com/github/beaten-by-the-market/seibro-api/blob/main/scenarios/combined/01_dilution.ipynb) · 원본: `krxnewsscrap/250713_dilution_dashboard_streamlit.py` (Streamlit 대시보드) · 구분: **이식 + 계산 수정**

## 한 줄 요약
종목 하나의 상장주식수에 아직 주식이 되지 않은 CB·BW 물량과 상장 대기 주식을 **더해** 희석 후 총주식수를 구하고, 상장주식 중 의무보유(보호예수)로 묶인 물량을 빼서 유통 가능 주식을 봅니다.

## 이렇게 물어보세요
- "한울앤제주 CB·BW가 다 전환되면 주식수가 얼마나 늘어?"
- "이 종목 지금 시장에서 거래될 수 있는 주식은 얼마나 돼?"
- "보호예수 걸린 물량이 얼마나 남았어?"

## 데이터 출처
| 항목 | 출처 | 패키지 함수 |
|---|---|---|
| 상장주식수·종가 | KRX 전종목 시세 | `krx_data_api.fetch("all_stock_price")` |
| 발행주식총수·고객번호 | SEIBRO `getStkStatInfo` | `SeibroClient.get_stock_info` |
| 주식 증감(감자·분할 등) | SEIBRO `getStkIncdecDetails` | `get_stock_issue_details` |
| CB·BW·EB 목록, 발행·잔액·현재 행사가, 누적 행사 | SEIBRO `getXrcStkStatInfo` + 웹 `issuInfoViewEL1`·`exerInfoView` + `getXrcStkOptionXrcInfo` | `get_stock_linked_bond_status` |
| 의무보유 예수·반환 | SEIBRO `getSafeDpDutyDepoStatus` (1년씩 나눠 조회) | `get_lockup_records`, `lockup_balance` |

## 원본 스크립트와 달라진 점
| 원본 | 이 노트북 |
|---|---|
| 유통주식 = 상장주식수 − 의무보유 − **전환가능주식수** (미발행 주식을 상장주식에서 뺌) | **희석 후 총주식수 = 상장주식수 + 상장 대기 + 전환·행사 가능 주식수**, 유통 가능 = 상장주식수 − 의무보유 |
| 모든 사채에 `미상환잔액 // 행사가` | CB는 미상환잔액, **BW는 발행금액 − 누적 행사금액**(미행사 신주인수권), EB는 주식수 불변이라 제외 |
| 예수 후 380일 넘은 미반환 건을 "장기미반환"으로 빼고 봄 | 감자·액면분할·병합 **이후 재예수된 낡은 기록**을 빼고, 1년 초과는 사유별로 **표시만** |
| `date.replace(year=-1)`로 기간 계산 (2월 29일에 오류) | 365일 구간으로 나눠 계산 |
| 최근 3년만 조회, 한계 언급 없음 | 기본 5년, 그 이전 예수분이 빠진다고 명시 |
| 원시 URL 호출(키가 URL에 들어감) | 패키지 함수로 호출, 오류 메시지에서 키를 가림 |

## 결과 예시 (한울앤제주 276730, KRX 2026-11-24, 노트북 실행값)
| 구성 | 주식수 | 상장주식수 대비 |
|---|---:|---:|
| 상장주식수 | 23,607,980 | 100% |
| ├ 의무보유 잔량(재등록 의심 제외) | 9,618,105 | 40.7% |
| └ 유통 가능 | 13,989,875 | 59.3% |
| 발행 완료·상장 대기 (11-13 유상증자, 11-27 상장) | 2,310,200 | 9.8% |
| CB 전환 가능 (10CB 7,495,085 + 12CB 183,387) | 7,678,472 | 32.5% |
| BW 행사 가능 (11BW) | 5,288,228 | 22.4% |
| **희석 후 총주식수** | **38,884,880** | **164.7%** |

- 10CB·11BW 현재 행사가 814원, 종가 925원(`주가/행사가` 1.14) → 지금 전환해도 이익이 나는 물량입니다.
- 12CB 행사가 18,540원은 발행 뒤 감자(2026-04)·액면분할(2026-07)이 있었는데 그 뒤 행사 기록이 없어 `행사가점검: 확인 필요`로 표시됩니다. 1:5 분할을 단순 반영하면 3,708원인데 그래도 주가의 4배라 당장 나올 물량은 아닙니다.
- 의무보유 미반환 단순 합계는 16,807,570주(상장주식의 71%)지만, 2025-12 예수 6,472,491주는 10:1 감자 뒤 647,249주로, 다시 1:5 분할 뒤 3,236,245주로 재예수돼 같은 주식이 세 번 잡혀 있습니다. 원본의 380일 규칙으로는 하나도 걸러지지 않습니다(가장 오래된 미반환 건이 344일).
- 원본 계산식이면 유통주식이 **−6,166,219주**로 나옵니다.

## 주의·한계
- **행사가는 SEIBRO 기록값**입니다. 리픽싱·감자·분할 반영이 늦을 수 있어 DART 전환가액 조정 공시로 확인해야 합니다.
- 행사기간 시작 전 물량도 포함합니다. 행사기간은 행사 실적이 있는 사채만 알 수 있습니다.
- **주식매수선택권 미행사분은 빠져 있습니다**(SEIBRO에 잔량 없음).
- 의무보유는 최근 5년 예수분만 보고, 반환 예정일은 API에 없습니다. `재등록의심`은 날짜만 보는 규칙입니다.
- `getSafeDpDutyDepoStatus`의 `TOTAL_STK_CNT`는 조회 시점 값입니다(예수 당시 값 아님).
- KRX 상장주식수는 실행 시점 최근 거래일 값입니다. 장중에 돌리면 그날 값이 나옵니다.
